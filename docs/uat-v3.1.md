## 附：验收流程与通过标准

### 验收流程

1. **代码检查**：grep / diff 验证 SYSTEM_PROMPT 替换和一致性
2. **构建验证**：`npm run build` 确认无编译错误
3. **AI 生成测试**：按第 5 节逐项手工测试，每次生成记录到 `temp/v3.1/`
4. **回归测试**：按第 6 节抽查 V1.0/V2.0 主流程
5. **报告输出**：结果写入 `temp/v3.1/uat-test-report-YYYY-MM-DD.md`

### 优先级定义

| 级别 | 定义 | 是否阻塞 V3.1 发布 |
|------|------|-------------------|
| P0 | Prompt 替换、构建成功、AI 生成核心质量 | 必须 100% 通过 |
| P1 | 回归测试、移动端适配、异常处理 | 必须 100% 通过 |
| P2 | 视觉细节、生成时间、边界场景 | >= 90% 通过 |

### V3.1 UAT 通过标准

- P0 用例通过率：**100%**
- P1 用例通过率：**100%**
- P2 用例通过率：**>= 90%**
- 无未关闭的 P0/P1 级 BUG
- 验收报告已存入 `temp/v3.1/`
- 以下项不阻塞发布：
  - V3.2 模板提示词结构化
  - V3.3 Remix 上下文增强
  - V3.4 后处理增强引擎
  - V3.5 多模型适配层
